# Capital Cleaners

Official website for **Capital Cleaners LLC**, a commercial cleaning and janitorial company serving businesses within approximately 30 miles of Bellevue, Washington.

## Website
Planned production domain: https://capitalcleanerswa.com

## Included
- Responsive commercial cleaning landing page
- Service and coverage sections
- Mobile navigation
- Free quote intake form
- Privacy policy
- LocalBusiness structured data
- SEO metadata, robots.txt and sitemap.xml

## Quote delivery
The current quote form is configured through FormSubmit for `info@capitalcleanerswa.com`. Before launch, make sure this mailbox exists and complete FormSubmit's one-time email activation after the first test submission. If a different business email is preferred, change the form `action` in `index.html`.

## Deployment
This is a static website and can be deployed on Cloudflare Pages, Netlify, Vercel, GitHub Pages, or most standard web hosts. Connect the production deployment to `capitalcleanerswa.com` and redirect `www.capitalcleanerswa.com` to the preferred canonical domain.
